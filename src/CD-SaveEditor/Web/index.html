CD-SaveEditor

1. Save found in the HDD

A timestamped copy of the HDD image is kept next to it before writing.

2. Export / import profiles

Writes a profile file straight into the xemu HDD image (the selected slot above), so you can carry a save between machines without booting the game.

3. Game files

The game rebuilds its profile from these defaults and rejects edited saves, so unlocking patches the game's startup config too. Start the game once afterwards.

4. Lock flags

Checked = unlocked (0). Unchecked = the game's own lock mask.

Saved as the game's defaults too, so it survives the next boot.
